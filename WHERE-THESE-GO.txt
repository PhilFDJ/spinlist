1. "NEVER PLAY" IS NOW A FLAG
-----------------------------
Every block editor — template builder, setup wizard, structure editor —
has a "Never play" button beside "Requests". Marked blocks show it in
coral with ⛔.

Same reason as the request block: "Do Not Play" was only a block someone
happened to name that. Rename it, or hand the gig to a sub-DJ who names
things differently, and the ban was invisible to any automation.

The default set still marks "Do Not Play", so nothing changes for the
weddings you already run this way.

A block can't be both. Marking one clears the other — a block that
collects guest requests to play can't also be the list of songs never to
play. You CAN have several never-play blocks.
